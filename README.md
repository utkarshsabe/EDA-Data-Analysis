# Sales Analysis Project

## Project Overview
This project performs Sales Analysis using Python. The project analyzes sales data to understand trends, sales performance, product categories, and relationships between variables using statistics and visualizations.

---

## Objective
The objective of this project is to analyze sales data and generate meaningful insights using charts and statistical analysis.

---

## Dataset Used
The dataset used in this project is:

**sales_data.csv**

The dataset contains the following columns:

| Column Name | Description |
|-------------|-------------|
| Product | Product name |
| Category | Product category |
| Price | Product price |
| Quantity | Quantity sold |
| Sales | Total sales |
| Region | Sales region |
